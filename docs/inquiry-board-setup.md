# 문의 접수 게시판 (구글 시트) 설정 방법

홈페이지로 들어온 모든 문의(견적문의 폼 · 채팅 상담 · 자료 다운로드 신청)를 **회사 구글 시트에 자동 저장**하고,
관리자 화면 **[문의 관리]**에서 목록·상태(신규/처리중/완료)를 관리하는 기능입니다.
메일 수신(Web3Forms·Formspree)과 **별도로 함께** 저장되므로, 메일을 놓쳐도 문의가 남습니다.

- 비용: 무료 (회사 구글 계정 사용)
- 소요 시간: 약 10분, 한 번만 설정
- 조회 비밀키(TOKEN)는 **본인만 보관**. 저장소·대화·문서에 적지 말 것

---

## 1단계. 구글 시트 만들기
1. 회사 구글 계정으로 https://sheets.google.com → **빈 스프레드시트**
2. 제목: `SMG 홈페이지 문의 접수`

## 2단계. 스크립트 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**
2. 기본으로 있는 내용을 모두 지우고, 저장소의 `docs/inquiry-board-apps-script.gs` 내용을 **전체 복사해 붙여넣기**
3. 조회 비밀키는 코드가 아니라 **스크립트 속성**에 저장: 왼쪽 톱니바퀴(프로젝트 설정) → 맨 아래 **스크립트 속성 → 속성 추가**
   → 속성 `TOKEN`, 값 = 본인만 아는 긴 비밀키(영문 대소문자+숫자 16자 이상) → 저장
   (코드를 새 버전으로 바꿔 붙여도 비밀키가 지워지지 않음. 비밀번호 관리 수단에 보관)
4. (선택) `NOTIFY_EMAIL` 에 메일 주소를 넣으면 접수 때마다 구글 메일로도 알림 → 메일 수신 이중화
5. 💾 저장 (Ctrl+S), 프로젝트 이름 `SMG 문의 접수`

## 3단계. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 설명: `SMG 문의 접수`
   - 다음 사용자 인증 정보로 실행: **나(본인 계정)**
   - 액세스 권한이 있는 사용자: **모든 사용자**  ← 홈페이지 방문자가 저장할 수 있어야 함
4. **배포** → 권한 검토 → 계정 선택 → "Google에서 확인하지 않은 앱" 화면이면 **고급 → (안전하지 않음)으로 이동** → **허용**
   (본인이 만든 스크립트라 정상 절차임)
5. 나오는 **웹 앱 URL** 복사 (`https://script.google.com/macros/s/……/exec`)

## 4단계. 홈페이지에 연결
1. 관리자 화면 → **[설정] → 문의 접수 게시판 (구글 시트)** → 웹앱 주소 붙여넣기
2. **[게시하기]**
3. 1~2분 뒤 견적문의 페이지에서 시험 문의 1건 전송 → 구글 시트 "문의" 탭에 한 줄 추가되는지 확인

## 5단계. 관리자에서 조회
1. 관리자 → **[문의 관리]** 맨 위 "문의 접수 게시판" 카드
2. 조회 비밀키(3단계의 TOKEN) 입력 → **[불러오기]**
3. 상태 칸에서 신규 / 처리중 / 완료 변경 → 시트에 바로 반영
- 비밀키는 그 브라우저에만 저장됨 (다른 PC에서는 다시 입력)

---

## 참고
- 웹앱 주소는 홈페이지 코드에 공개적으로 들어갑니다. 저장만 가능하고, **조회·변경은 비밀키가 있어야만** 됩니다.
- 스크립트를 수정했다면 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포** 해야 반영됩니다 (주소는 유지).
- 비밀키가 노출되면: 프로젝트 설정 → 스크립트 속성의 TOKEN 값 변경 → 관리자에서 새 비밀키로 다시 불러오기 (재배포 불필요).
- 시트는 일반 구글 시트이므로 필터·정렬·다운로드(엑셀) 자유롭게 사용 가능. 단 **1행(제목)과 열 순서는 바꾸지 말 것**.
- 개인정보: 문의자 정보가 회사 구글 드라이브에 저장됩니다. 보유기간(3년)이 지난 행은 정기적으로 삭제하세요.

## 현재 연결 상태 (2026-11-13)
- 시트: "SMG 홈페이지 문의 접수" (박장훈 계정 소유). 웹 앱 주소는 `data/site-data.js`의 `sheetEndpoint`
- 탭 구성
  - **현황**: 전체·신규·처리중·완료·이번 달·최근 7일·2일 넘은 신규 건수, 경로별·유형별 건수, 미처리 문의 목록 (자동 계산)
  - **문의** 열 순서(2026-11-13 재배치): 담당 팀 · 제품 분류 · 상태 · 견적 요청일 · 회신 기한 · 회사명 · 확인 필요 · 유형 · 담당자 · 직급·직책 · 연락처 · 이메일 · **사내 담당 · 처리 메모 · 회신일 · 다음 조치일 · 대응 구분**(사내 입력) · 관심제품 · 수량/납기 · 견적품목 · 내용 · 접수일시 · 경로 · 최종 업데이트 · 언어 · 페이지 · 제목
- 앞 6열(담당 팀~회사명)과 1행은 틀 고정. 담당 팀·제품 분류는 보라색 강조
- 견적 요청일(D열)은 접수일시의 날짜를 자동 표시(수식). 회신 기한과 나란히 굵게 표시
- 데이터 행은 높이 30·세로 가운데 정렬·줄바꿈 없음(긴 내용은 셀 선택 시 위 수식줄에서 확인)
- 상태(C열)는 드롭다운(신규·처리중·완료)이며 색으로 구분. 완료된 행은 회색 글씨
- 언어·페이지·제목(Y~AA열)은 접어 둠. 열 위 [+]를 누르면 펼쳐짐
- 머리글과 자동 입력 칸(사내 입력 열·상태 제외)은 수정하면 경고가 뜸 (실수 방지, 수정은 가능)
- 연락처 열은 텍스트 서식 (010 앞자리 0 보존)
- 관리자 [문의 관리] 게시판은 열려 있는 동안 60초마다 시트를 다시 읽음. 상태는 시트와 관리자 화면 어느 쪽에서 바꿔도 서로 반영됨
- 1,000행을 넘으면 새 행에 서식이 자동 적용되지 않으므로 오래된 완료 건을 다른 탭으로 옮기거나 서식을 아래로 복사할 것
- 시트 공유는 필요한 사람만 "편집자"로 추가. 링크 공개는 하지 말 것 (연락처 등 개인정보 포함)

## 2026-11-13 개편: 영업 대응용 시트 구성
| 탭 | 용도 | 입력 |
|---|---|---|
| **현황** (첫 탭) | 목록의 회사명을 누르면 해당 탭의 그 행으로 이동. ① 견적·기술 문의(메인, 빨강, 팀별 대응 현황 포함): 회신 기한 초과·오늘 기한·신규·처리중·완료, 회신 대응 목록(기한 빠른 순) / ② 자료 다운로드(잠재, 파랑): 연락처 남긴 다운로드·미연락·관심 업체 수, 다운로드 신청 목록 | 자동 |
| **문의** | 견적·기술 문의만 (자료 다운로드는 여기 쌓이지 않음). 회신 기한 = 접수일 + 표준 2영업일 / 주문 제작 5영업일 (대응 구분 열, 주말 제외). 제품 분류(홈페이지에서 자동)로 담당 팀이 자동 배정됨. 기한이 지나면 행 전체가 빨갛게 표시 | 상태·사내 담당·처리 메모·회신일·다음 조치일·대응 구분 |
| **다운로드 이력** | 자료를 받을 때마다 한 줄. 연락처를 남긴 다운로드는 "연락처 남김", 아니면 "익명"(회색) | 후속 상태(미연락·연락함·견적 전환·관심 없음)·사내 담당·메모 |
| **관심 업체** | 문의·다운로드한 회사를 회사별로 자동 정리. 업무 메일 도메인으로 홈페이지를 추정하고, 홈페이지 첫 화면의 제목·설명으로 "회사 정보"를 자동 채움 (뒤에 "(자동)" 표시, 틀리면 고쳐 쓰면 됨) | 직급·직책·등급(A/B/C)·영업 담당·메모 |
| **변경 로그** | 문의·다운로드 이력·관심 업체 탭에서 사람이 고친 내용(이전 값→새 값)과 관리자 화면의 상태 변경 | 자동 (수정 금지) |
| **설정** | 영업 담당자 이름·직급·소속 팀(드롭다운 원본), 제품 분류 → 담당 팀 표. 소속 팀·담당 팀 칸은 드롭다운(영업1~3팀, 새 팀은 직접 입력 가능) | 담당자 추가, 제품별 담당 팀 지정 |

### 입력 누락 방지 규칙
- 상태를 **처리중**으로 바꾸려면 **사내 담당**이 먼저 있어야 함
- 상태를 **완료**로 바꾸려면 **사내 담당·처리 메모·회신일**이 모두 있어야 함
- 조건이 안 맞으면 시트에서는 상태가 원래대로 되돌아가고 안내 메시지가 뜸. 관리자 화면에서도 같은 규칙으로 거부됨
- 빈 필수 칸은 빨간 칸, 처리중인데 다음 조치일이 없거나 지난 경우 주황 칸, "확인 필요" 열에 해야 할 일이 글로 표시됨
- 설정 탭의 "제품 분류 → 담당 팀" 표(E·F열) 위치는 바꾸지 말 것
- 모든 열은 **머리글 이름**으로 찾으므로 열 순서를 바꿔도 되지만 **머리글 글자는 바꾸지 말 것**

### 적용 순서 (스크립트 코드 변경 시)
1. 프로젝트 설정 → 스크립트 속성에 `TOKEN` (처음 한 번)
2. 코드 전체를 `docs/inquiry-board-apps-script.gs`로 교체 → 저장
3. 배포 → 배포 관리 → 편집 → 버전 "새 버전" → 배포 (웹 앱 주소 유지)
4. (필요 시) 함수 `enrichAll` 실행: 회사 정보가 빈 관심 업체를 홈페이지에서 채움 / `rebuildClients`: 관심 업체 집계 재계산
- 수정자 칸은 같은 구글 워크스페이스 계정이 아니면 비어 있을 수 있음 (구글 정책)
