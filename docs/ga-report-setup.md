# 방문 통계 자동 기록 (Google Analytics → 구글 시트) 설정 방법

리뉴얼 홈페이지 공개일(2026-11-05)부터의 **접속자 수, 페이지뷰, 머문 시간, 클릭(이벤트), 문의 건수**를
구글 시트에 매일 자동으로 쌓는 기능입니다. 시트에 쌓인 데이터로 조이·Claude가 주간·월간 보고서를 만듭니다.

- 비용: 무료 (Google Apps Script)
- 소요: 약 10분, 처음 한 번만
- 필요한 것: Google Analytics 속성 `smg-338ba`에 접근 권한이 있는 구글 계정

## 1. 시트 만들기
1. 구글 드라이브에서 새 스프레드시트를 만들고 이름을 `SMG 홈페이지 방문 통계`로 지정
2. 메뉴 **확장 프로그램 → Apps Script**

## 2. 스크립트 붙여넣기
1. 기본으로 들어 있는 코드를 모두 지우고 `docs/ga-report-apps-script.gs` 내용을 붙여넣기
2. 맨 위 `PROPERTY_ID`가 GA4 속성 ID와 같은지 확인 (GA 관리 → 속성 설정 → 속성 ID, 숫자)
3. 왼쪽 **서비스 +** → **Google Analytics Data API** 선택 → 추가
4. 저장 (디스크 아이콘)

## 3. 처음 실행
1. 위쪽 함수 선택에서 `installTrigger` 선택 → **실행**
2. 권한 요청 창에서 본인 계정 선택 → 허용
3. 시트에 `일별`, `이벤트_일별`, `페이지_28일`, `유입_28일`, `국가_28일`, `기기_28일` 탭이 생기고 데이터가 채워지면 완료
4. 이후 매일 오전 7시대에 자동 갱신

## 4. 시트 구성

| 탭 | 내용 | 기록 방식 |
|---|---|---|
| 일별 | 날짜별 사용자·신규 사용자·세션·페이지뷰·평균 세션 시간(초)·참여율·이탈률 | 공개일부터 누적 |
| 이벤트_일별 | 날짜별 이벤트 횟수 (`generate_lead` 문의 접수, `download_click`, `tel_click`, `video_play` 등) | 공개일부터 누적 |
| 페이지_28일 | 페이지별 조회수·사용자·총 참여 시간 | 최근 28일, 매일 새로 씀 |
| 유입_28일 | 채널·출처별 세션 | 최근 28일 |
| 국가_28일 / 기기_28일 | 국가·기기별 사용자 | 최근 28일 |

- 평균 머문 시간(페이지별) = 총 참여 시간 ÷ 사용자
- 이벤트 이름의 뜻은 `docs/operations-manual.md` 13-2 표 참고

## 5. 보고서 받기
- 시트를 Claude(조이)가 읽을 수 있게 공유하거나, Claude에 구글 시트 연결이 되어 있으면 시트 이름만 알려주면 됨
- 요청 예: "방문 통계 시트로 지난주 보고서 만들어줘"

## 주의
- GA 수치는 집계에 하루 정도 걸려 **어제까지**만 기록됨. 오늘 수치는 GA 실시간 보고서에서 확인
- 클릭·문의 이벤트는 2026-11-13 이벤트 추가 이후부터 집계됨 (그 전 기간은 방문·페이지뷰만 있음)
- 시트에는 개인정보가 들어가지 않음 (집계 수치만). 문의 내용은 별도의 문의 접수 게시판 시트(`docs/inquiry-board-setup.md`)에 저장
- 담당자가 바뀌면 시트 소유권을 넘기고, 새 담당자 계정으로 `installTrigger`를 다시 실행
- 스크립트가 실패하면 Apps Script 화면 왼쪽 **실행** 탭에서 오류 내용을 확인
