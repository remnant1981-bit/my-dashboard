# 홈페이지 마케팅 지표 자동 기록 (GA4 + Search Console + 네이버) 설정 방법

홈페이지 **방문자 수·검색 노출수·키워드 순위·문의/다운로드**를 구글 시트 `SMG 홈페이지 마케팅 지표`에 자동으로 쌓고,
매월 1일 지난달 요약을 관리자 메일로 보내는 기능입니다. (2026-11-16 확장: 기존 "방문 통계" 기능 + 검색 노출·순위)

- 비용: **무료** (Google Apps Script · GA4 · Search Console · 네이버 검색 API). 유료 크레딧·외부 도구 사용 안 함
- 시트: 구글 드라이브 `SMG 홈페이지 마케팅 지표` (관리자 소유, 키워드·기준값 입력 완료). 주소는 저장소에 적지 않음
- 필요한 것: GA4 속성 `smg-338ba`와 Search Console `https://www.sungsil.com` 권한이 있는 같은 구글 계정

## 1. 스크립트 붙여넣기 (처음 한 번, 약 10분)
1. 시트 열기 → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 모두 지우고 `docs/ga-report-apps-script.gs` 붙여넣기
3. 왼쪽 ⚙ **프로젝트 설정** → "편집기에서 appsscript.json 매니페스트 파일 표시" 체크 → 편집기의 `appsscript.json` 내용을 `docs/ga-report-appsscript.json`으로 교체
   (Google Analytics Data API 서비스·검색콘솔 읽기 권한이 함께 설정됨)
4. 저장

## 2. 스크립트 속성 (⚙ 프로젝트 설정 → 스크립트 속성)
| 이름 | 값 | 비고 |
|---|---|---|
| `REPORT_TO` | 월간 요약 받을 메일 (예: 관리자 메일) | 비우면 메일 안 보냄 |
| `NAVER_ID` | 네이버 검색 API Client ID | 담당자가 직접 입력 (저장소·대화에 적지 말 것) |
| `NAVER_SECRET` | 네이버 검색 API Client Secret | 〃 |

**네이버 검색 API 키 받기 (무료, 5분)**: developers.naver.com → Application → 애플리케이션 등록 → 사용 API **검색** 선택 → 환경 "WEB 설정", URL `https://www.sungsil.com` → 등록 후 Client ID·Secret 확인. 하루 25,000회 무료 (월 1회 20여 건 사용).
키가 없으면 네이버 순위만 건너뛰고 나머지는 정상 기록됨.

## 3. 처음 실행
1. 함수 `installTrigger` 선택 → 실행 → 권한 허용 (Analytics·Search Console 읽기, 메일 발송, 예약 실행)
2. 함수 `순위측정` 1번 실행 → 키워드_순위 탭에 오늘 날짜 행이 추가되면 정상
3. 이후 매일 오전 7시대 자동 갱신, 매월 1일 키워드 순위 측정 + 월간 요약 메일

## 4. 시트 구성
| 탭 | 내용 | 갱신 |
|---|---|---|
| **월별 요약** | 월별 사용자·페이지뷰·체류시간·문의/다운로드/전화 클릭·구글 노출수·클릭수·CTR·평균 순위·1페이지 키워드 수(구글/네이버) | 매일 |
| 키워드 | 측정할 키워드 목록 (구분·키워드·사용 체크) — **사람이 직접 관리** | 분기 1회 점검 |
| 키워드_순위 | 측정일·엔진·키워드·순위·노출 URL (누적) | 매월 1일 |
| 측정 방법 | 지표 정의·출처·판단 기준 | — |
| 일별 / 이벤트_일별 | GA4 날짜별 방문·이벤트 (공개일부터 누적) | 매일 |
| 검색_일별 | 서치콘솔 날짜별 노출수·클릭수·CTR·평균 순위 | 매일 (2~3일 지연) |
| 검색어_28일 / 검색페이지_28일 | 최근 28일 검색어·페이지별 노출·클릭·순위 | 매일 |
| 페이지·유입·국가·기기_28일 | GA4 최근 28일 순위표 | 매일 |

## 5. 지표 해석
- **구글 키워드 순위** = 서치콘솔 실제 평균 게재 순위(최근 28일, 검색어 정확히 일치). 노출이 없으면 빈칸
- **네이버 키워드 순위** = 검색 API 웹문서 100건 중 sungsil.com 순위 (화면의 통합검색 순서와 다를 수 있음)
- **기준값(2026-11-16)** 은 검색 결과 화면을 직접 측정한 값이라 이후 자동 측정과 방식이 다름 → 추세 참고용
- 한 달 값보다 **3개월 추세**로 판단. 네이버 노출수·클릭수는 서치어드바이저(소유확인 후)에서 월 1회 확인

## 주의
- GA 수치는 하루, 서치콘솔은 2~3일 늦게 확정됨
- 시트에는 개인정보 없음 (집계 수치만). 문의 내용은 문의 접수 게시판 시트(`docs/inquiry-board-setup.md`)
- 담당자 변경 시 시트 소유권 이전 후 새 담당자 계정으로 `installTrigger` 다시 실행, 네이버 키도 새로 입력
- 오류는 월별 요약 탭 A1 셀 메모("마지막 갱신 · 오류")와 Apps Script 왼쪽 **실행** 탭에서 확인
