| 사이트 전체 안 열림 | DNS 변경·GitHub 장애 | DNS 레코드 확인(4장), githubstatus.com 확인 |
| 수정한 내용이 안 보임 | 브라우저 캐시·게시 미완료 | Ctrl+F5, 1~2분 대기, 관리자 게시 결과 확인 |
| 문의 메일이 안 옴 | 스팸함·서비스 한도·장애 | 스팸함 → Web3Forms/Formspree 대시보드 제출 수 → `?backuptest=1` 시험 |
| 영문 화면에 한글 | 영문 데이터 누락·미리보기 임시저장 | 관리자 EN 데이터 확인, 탭 닫고 재접속 |
| 카톡 미리보기가 옛 정보 | 카카오 캐시 | 카카오 디벨로퍼스 "공유 디버거"에서 캐시 초기화 |
| 큰 문제 발생 | 최근 변경 | 직전 PR 되돌리기(revert) 후 원인 확인 |

## 10. 운영 원칙 (배포 상태)

1. **전면 개편·디자인 전면 변경 금지.** 현재 구조와 디자인을 기준으로 유지
2. 개선은 **작은 단위로 수시 제안** → 승인 → 반영 → 실사이트 확인
3. 제안 형식: 무엇을 / 왜(사용자 영향) / 영향 범위 / 되돌리는 방법 / 우선순위(상·중·하)
4. 우선순위: 오류·깨진 링크 > 문의 흐름 > 오탈자·사양 정확성 > 검색 노출 > 사용성 미세 조정
5. 코드 변경은 반드시 테스트(국문·영문 × PC·모바일) 후 PR, 병합은 훈이님 승인
6. 생성물(`en/*.html`, `product/*.html`, `en/product/*.html`)은 직접 수정하지 않고 생성기로 재생성

| 기능 | 어디서 설정 | 사용법 |
|---|---|---|
| 공지 상세 페이지 | 자동 | 공지 목록 클릭 → `notice.html?id=…` 상세(이전/다음 글). 관리자 [공지사항]에서 쓰면 자동 생성 |

| 자료 다운로드 연락처 | [설정] → 자료 다운로드 연락처 | 끄기 / 선택(건너뛰기 가능, 기본) / 필수. 입력 내용은 "자료 다운로드" 유형 문의로 메일·시트 접수. 같은 방문 중에는 한 번만 물음 |
| 인증서 원본 보기 | [회사소개 · 인증] → 인증 편집 | 인증번호·유효기간·원본(이미지/PDF) 등록 → 메인·회사소개 인증 목록에 "원본 보기" 버튼. 유효기간 지나면 "갱신 확인 중" 표시 |
| 제품 사양 비교 | 자동 | 제품 상세의 [사양 비교] 또는 제품소개의 "제품 사양 비교" → 최대 3개 나란히, 값이 다른 줄은 색 표시. 주소 공유 가능 (`compare.html?ids=str,stc`) |
