# 숨고 견적 응답 문구 (업종별 변형)

> 원칙: ① 질문 먼저, 가격은 범위로 ② 수집 가능 여부(약관·개인정보) 확인을 응답에 포함 ③ 없는 실적·후기 언급 금지
> ④ 겸업 허가 확인 전에는 견적을 보내지 않음 (`contract_checklist.md` 0번) ⑤ 가격 범위는 `templates/quote_and_scope.md` 4번 기준(조사 평균, 추정)

## 공통 골격 (150~250자)
안녕하세요. 요청하신 **[작업명]**은 **[방식]**으로 제작 가능해 보입니다. 정확한 견적을 위해 아래 3가지만 알려주세요.
1) [질문 1] 2) [질문 2] 3) [질문 3]
참고로 로그인이 필요한 서비스와 개인정보 수집은 진행하지 않으며, 대상 사이트의 이용약관·robots.txt를 먼저 확인합니다. 예상 범위는 **[가격 범위]**, 작업 기간은 **[N]일**입니다.

## 업종별 변형

### 1) 쇼핑몰 상품 가격·재고 모니터링 (공개 상품 페이지)
- 질문: ① 대상 사이트 주소 2~3개와 수집 항목 ② 확인 주기(1일 1회? 매시간?) ③ 변동 시 알림이 필요한지(메일/메신저)
- 범위: 정적/동적 페이지 수집 + 변경 감지 알림 / 15~30만(추정)
- 주의: 대형 쇼핑몰은 자동 수집 금지 조항이 있을 수 있음 → 약관 확인 후 안내, 어려우면 대안 제시

### 2) 부동산·매물 공개 정보 정리
- 질문: ① 수집할 지역·조건 ② 필요한 항목(가격·면적·위치 등) ③ 사용 목적(내부 분석인지 재배포인지)
- 범위: 공개 목록 수집 + 엑셀 정리 / 8~30만(추정)
- 주의: **재배포·상업적 재판매 목적이면 데이터베이스권·약관 문제 소지** → 목적 확인 후 수주 판단, 개인정보(연락처 등)는 수집 제외

### 3) 채용·입찰 공고 모니터링
- 질문: ① 대상 사이트와 키워드 ② 새 공고 알림 필요 여부 ③ 결과 형식(엑셀/메일)
- 범위: 키워드 필터 수집 + 신규 공고 알림 / 15~30만(추정)
- 주의: 공공 입찰 정보는 공공 API가 있는 경우가 많음 → API 우선 제안 (더 안정적)

### 4) 경리·총무 엑셀 취합 (지점·부서별 파일)
- 질문: ① 파일 개수와 형식(xlsx/csv, 한글 깨짐 여부) ② 합칠 항목과 원하는 보고서 모양 ③ 매월 반복인지
- 범위: 파일 자동 취합 + 월별 피벗/요약 시트 / 8~25만(추정)
- 응답 예: "한글 CSV(cp949)·엑셀 혼합, 잠금파일, 양식이 다른 파일도 걸러서 경고로 알려드리는 방식으로 만들 수 있습니다."

### 5) 공공데이터 수집·정리
- 질문: ① 어떤 데이터(기관·주제) ② 갱신 주기 ③ 기존에 쓰는 API 키가 있는지
- 범위: 공공 API/파일 수집 + 정리 + 엑셀 / 8~25만(추정)
- 주의: 이용 조건·출처 표기 확인. 키는 의뢰인 발급분을 환경변수로 사용

### 6) 뉴스·보도자료 키워드 수집
- 질문: ① 키워드와 기간 ② 대상 매체 ③ 요약/분류가 필요한지
- 범위: 목록 수집(제목·날짜·링크) + 엑셀 / 8~15만(추정)
- 주의: 기사 본문 대량 수집·재배포는 저작권 문제 → 제목·링크·날짜 중심으로 제안

## 거절·보류 응답 템플릿
### 로그인/개인정보/약관 위험
문의 감사합니다. 말씀하신 작업은 **[로그인이 필요한 서비스 / 개인정보 수집 / 약관상 자동 수집 금지]**에 해당할 가능성이 높아 제가 진행하기 어렵습니다. 공개 API나 제공 기관의 공식 데이터 이용 같은 **대안**이 있다면 함께 검토해 드릴 수 있습니다.

### 정부지원사업 제출 문서 대필 요청
사업계획서 등 제출 문서의 작성 대행은 진행하지 않습니다. (구성 점검·첨삭 형태는 [가능 여부] 별도 안내)

### 범위가 모호할 때
요구사항이 정해지면 정확한 견적을 드릴 수 있습니다. 예시 파일/화면 1개와 원하는 결과 엑셀의 모양을 보내주시면 확인 후 24시간 내 회신드리겠습니다. *(회신 시간 약속은 실제로 지킬 수 있을 때만 사용)*
