## 4. 상세 설명 본문 초안 (상품 1: 웹 데이터 수집)

### 이런 분께 필요합니다
- 웹사이트에서 같은 데이터를 매번 복사·붙여넣기 하는 분
- 수집한 데이터를 엑셀로 다시 정리하느라 시간을 쓰는 분
- 한글 페이지·한글 엑셀 파일(cp949)에서 글자가 깨져 고생한 분

### 받으시는 것
1. 원하는 웹페이지의 목록·상세 데이터를 엑셀(CSV)로 저장하는 프로그램 (소스코드)
2. 실행 방법 설명서와 샘플 결과 파일
3. 수집 결과 자동 검증(건수 확인, 빈 값·형식 이상 표시) — 상위 패키지
4. 정기 실행(작업 스케줄러 등록) 안내 — 프리미엄

### 작업 범위
| 포함 | 제외 |
|---|---|
| 수집 대상 1개 사이트, 항목 협의 후 확정 | 로그인이 필요한 서비스, 개인정보 수집 |
| 한글 페이지 인코딩 처리, 엑셀 서식 정리 | 이용약관·robots.txt 위반 소지가 있는 사이트 |
| 수정 횟수 내 선택자·형식 수정 | 대상 사이트 구조 변경 후 유지보수 (별도 협의) |

### 진행 과정
문의 → 요구사항 확인(문진표) → 약관·수집 가능 여부 확인 → 견적 → 제작 → 납품·검수 → 수정

### 작업 사례 (시연 데이터)
- 한국어 위키백과의 표를 수집해 각주·빈칸·괄호 숫자를 정리하고 엑셀로 저장
- 정리 후 시도별 합계를 원본의 '계' 행과 자동 대조 → **원본 표 자체의 불일치를 발견해 경고** (`demo/README.md`)
- 지점별 CSV(cp949·utf-8 혼합, 잠금파일, 양식 오류 파일 포함) 5개를 취합해 월별 피벗 생성 (가상 데이터)
- ※ 위 이미지는 결과 시트를 표로 그린 **미리보기**이며, 가상 데이터·출처(CC BY-SA 4.0) 표기를 유지할 것

### FAQ
- **로그인해야 보이는 데이터도 되나요?** 로그인이 필요한 서비스와 개인정보는 수주하지 않습니다.
- **어떤 사이트든 가능한가요?** 이용약관·robots.txt를 먼저 확인하고, 위험이 있으면 수주를 거절하거나 대안(공공 API 등)을 안내합니다.
- **사이트가 바뀌면요?** 구조 변경으로 인한 수정은 별도 협의입니다 (납품 후 7일간은 납품 범위 내 버그 무상 수정).
- **소스코드는 받나요?** 대금 완납(구매확정) 시 의뢰인에게 귀속됩니다.
- **파이썬이 없는 PC인데요?** 설치 안내를 드리며, 원격 설치 지원은 별도 협의입니다.
- **체험과 DELUXE는 뭐가 다른가요?** 체험은 제가 수집한 **결과 파일만** 1회 드립니다. DELUXE부터는 직접 반복 실행할 수 있는 프로그램과 소스코드를 드립니다. (안 A: STANDARD 칸이 체험)
- **체험 범위를 넘으면요?** 항목·행 수가 범위를 넘거나 동적 페이지인 경우 DELUXE 이상 또는 견적(8만원~)으로 안내드립니다.

## 6. 가격 포지셔닝
**결정(2026-11-13): 체험 패키지 추가, 배치는 안 A로 확정** (STANDARD 칸 = 체험 4만 / DELUXE 15만 / PREMIUM 30만, 8만원은 견적). 붙여 넣을 최종 문구는 `listing_final_kmong.md`.

| 구성 | 가격 | 납품물 | 역할 |
|---|---|---|---|
| 체험 (첫 거래용) | 4만 | 수집 결과 파일 1회 (프로그램·소스 미포함) | 진입가를 낮춰 첫 리뷰 확보, 상위 패키지로 전환 |
| STANDARD | 8만 | 프로그램 + 소스 | 정적 페이지 1개 |
| DELUXE | 15만 | 프로그램 + 소스 | 동적(JS) 페이지 + 페이지 넘김 |
| PREMIUM | 30만 | 프로그램 + 소스 | 변경 감지 알림 + 정기 실행 안내 |

**체험 패키지에 대해 시뮬레이션이 말해주는 것** (`simulation/RESULTS.md`, 입력값은 가정)
- 체험을 넣었는데 수주가 늘지 않으면 **소폭 손해**임 (기존 8만원 주문 일부가 4만원으로 내려가기 때문).
- 손익분기는 수주 약 **+10~15%**. +30% 이상 늘면 실수령과 리뷰 수가 모두 늘어남.
- 다만 문의가 적은 기본 가정에서는 체험을 넣어도 26주 내 100만원 달성 확률이 1% → 1~5% 수준임. **체험만으로 노출 병목이 풀리지는 않음.**
- 그래서 체험은 "리뷰 5건 확보까지" 한시 운영하고, 그 기간의 실제 수주 변화를 보고 유지 여부를 정하는 것을 권장.

**상세 페이지에 넣을 체험 안내 문구(안)**
> 처음이라 망설여진다면 **체험 패키지**로 시작해 보세요. 공개된 웹페이지 1곳에서 원하는 항목(5개 이하, 최대 300행)을 수집해 엑셀 파일로 드립니다. 결과를 보고 마음에 들면 직접 실행할 수 있는 프로그램 제작(STANDARD 이상)으로 이어가실 수 있습니다. ※ 체험은 결과 파일만 제공하며, 로그인이 필요한 사이트·개인정보·약관상 수집이 금지된 사이트는 진행하지 않습니다.
