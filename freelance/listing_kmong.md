# 크몽 상품 등록 초안

## 상품 1: 웹 데이터 수집(크롤링) → 엑셀 자동 저장
**제목**: 웹사이트 데이터 수집 크롤링 프로그램 제작 (Python/Selenium, 엑셀 저장)
**소개**
- 공개된 웹페이지 데이터를 자동 수집해 엑셀/CSV로 저장하는 프로그램을 제작합니다. (수집 가능 여부는 대상 사이트 약관·robots.txt 확인 후 안내드립니다.)
- 동적 페이지(JS 렌더링)는 Selenium으로 대응합니다.
- 실행 가이드와 소스코드를 함께 납품합니다.
**작업 범위**: 수집 대상 1개 사이트, 항목(컬럼) 협의 후 확정(기본 패키지 기준 최대 10개), 결과 엑셀 저장, 사용법 문서
**제외**: 로그인 필요 서비스, 개인정보 수집, 약관·로봇배제 위반 소지 사이트
**패키지(안)**
| 구분 | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 가격(초기 리뷰용 안) | 8만 | 15만 | 30만 |
| 범위 | 정적 페이지 1개 | 동적(JS) 페이지 + 페이지 넘김 수집 | 위 + 변경 감지 알림 + 윈도우 작업 스케줄러 등록 안내 |
| 수정 | 1회 | 2회 | 3회 |
| 작업일 | 3일 | 5일 | 7일 |
**FAQ**: 소스 소유권은 대금 완납(구매확정) 시 의뢰인에게 귀속 / 대상 사이트 약관 확인 후 수주 / 대상 사이트 구조 변경 시 선택자 수정은 별도 협의

## 상품 2: 엑셀 업무 자동화 (취합·보고서)
**제목**: 엑셀 취합·보고서 자동화 (Python/VBA)
**소개**: 여러 파일 취합, 요약 시트 생성, 서식 자동 적용을 버튼 한 번 또는 스크립트 한 번으로 처리합니다.
**패키지(안)**: 8만 / 15만 / 25만

## 포트폴리오 이미지에 쓸 샘플
`demo/images/` 결과 미리보기 3장 (한글 데이터 데모. 가상 데이터·출처·'미리보기' 표기 필수, 가능하면 실제 엑셀 화면으로 교체) + `samples/` 실행 화면

## 가격·수익 유의 (내부용, 상품 설명에는 넣지 않음)
- 플랫폼 수수료(크몽 약 20%, 추정·확인 필요)와 세금을 빼면 실수령은 표기 가격보다 낮음
- 예: 15만원 상품 → 수수료 후 약 12만원(추정), 소득세 별도 → 100만원 실수령에는 총 매출 약 125만원 이상 필요(추정)
- 초기 리뷰용 가격(8만원)은 실수령이 매우 낮으므로 건수 제한 권장
