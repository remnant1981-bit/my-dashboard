# 크몽 상품 등록 초안

## 상품 1: 웹 데이터 수집(크롤링) → 엑셀 자동 저장
**제목**: 웹사이트 데이터 수집 크롤링 프로그램 제작 (Python/Selenium, 엑셀 저장)
**소개**
- 공개된 웹페이지 데이터를 자동 수집해 엑셀/CSV로 저장하는 프로그램을 제작합니다. (수집 가능 여부는 대상 사이트 약관·robots.txt 확인 후 안내드립니다.)
- 동적 페이지(JS 렌더링)는 Selenium으로 대응합니다.
- 실행 가이드와 소스코드를 함께 납품합니다.
**작업 범위**: 수집 대상 1개 사이트, 항목(컬럼) 협의 후 확정(기본 패키지 기준 최대 10개), 결과 엑셀 저장, 사용법 문서
**제외**: 로그인 필요 서비스, 개인정보 수집, 약관·로봇배제 위반 소지 사이트
**패키지(안)**
| 구분 | 체험 (첫 거래용) | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|---|
| 가격(초기 리뷰용 안) | **4만** | 8만 | 15만 | 30만 |
| 납품물 | **수집 결과 파일(엑셀/CSV) 1회** — 프로그램·소스 미포함 | 프로그램 + 소스 + 사용법 | 좌동 | 좌동 |
| 범위 | 공개 정적 페이지 1개, 항목 5개 이하, 최대 300행 | 정적 페이지 1개 | 동적(JS) 페이지 + 페이지 넘김 수집 | 위 + 변경 감지 알림 + 윈도우 작업 스케줄러 등록 안내 |
| 수정 | 1회 | 1회 | 2회 | 3회 |
| 작업일 | 2일 | 3일 | 5일 | 7일 |

**체험 패키지 운영 규칙**
- 목적은 수익이 아니라 **첫 리뷰 확보와 상위 패키지 전환**임. 결과가 마음에 들면 STANDARD 이상(프로그램 납품)으로 안내.
- 제외: 동적(JS) 페이지, 정기 수집, 프로그램·소스 납품, 로그인·개인정보·약관 위반 소지 사이트
- 체험은 제작자가 **직접 수집을 실행해 결과를 넘기는 방식**이라 약관·robots.txt 확인 책임이 더 직접적임 → `tools/check_robots.py` 결과와 약관 확인을 건마다 기록
- 건수 제한 권장: 리뷰 5건 확보 시점까지만 운영 후 유지 여부 재검토 (아래 "가격·수익 유의" 참고)

**패키지 칸 배치 — 크몽은 한 상품에 패키지 3칸(STANDARD / DELUXE / PREMIUM)임** (크몽 '용역 서비스 등록 가이드' 2026.01.19: "패키지 설정을 활용하면 3개의 가격 옵션으로 구성"). 위 4단 구성을 한 상품에 그대로 넣을 수는 없으므로 아래 중 선택.
| 안 | 크몽 3칸 배치 | 비고 |
|---|---|---|
| 안 A (권장) | STANDARD 칸 = 체험 4만 / DELUXE 칸 = 15만 / PREMIUM 칸 = 30만. 기존 8만원 상품(정적 1개 프로그램 납품)은 문의 후 견적으로 안내 | 체험과 8만원 상품이 가장 겹치므로 8만원을 뺌. 리뷰가 본 상품에 쌓임 |
| 안 B | 본 상품은 8 / 15 / 30만 유지, 체험은 별도 상품으로 등록 | 노출 면적은 늘지만 리뷰가 상품별로 나뉠 수 있음 (집계 방식 미확인) |

**FAQ**: 소스 소유권은 대금 완납(구매확정) 시 의뢰인에게 귀속 (체험은 소스 미포함) / 대상 사이트 약관 확인 후 수주 / 대상 사이트 구조 변경 시 선택자 수정은 별도 협의

## 가격·수익 유의 (내부용, 상품 설명에는 넣지 않음)
- **크몽 판매 수수료(공식 '판매 수수료 정책', 2024.08.20 게시, 2026-11-13 확인)**: 서비스 이용료(판매 금액 70만원까지 16.4%, 70만~200만 구간 9.4%, 200만 초과 구간 4.4%) + 결제망 이용료 3.3%, 그 합계에 부가세 10%. 70만원 이하 건의 실효율은 **21.67%**. 구간은 건당 금액 기준으로 해석했고 카테고리에 따라 달라질 수 있으므로 크몽 [판매 관리 > 수익 관리 > 수익금 계산기]로 최종 확인할 것
- 건당 실수령(원천징수 3.3% 가정 포함): 4만 → 3.03만 / 8만 → 6.06만 / 15만 → 11.36만 / 30만 → 22.72만. **실수령 100만원에는 총 판매액 약 132만원 필요** (원천징수는 가정, 미확인)
- 초기 리뷰용 가격(8만원)은 실수령이 매우 낮으므로 건수 제한 권장
- **체험 패키지(4만원)**: 실수령 약 3.03만원. 작업 1.5일 가정이면 하루 약 2만원 수준이라 그 자체로는 수익이 안 됨
- 시뮬레이션(`simulation/RESULTS.md`): 체험을 넣고 **수주가 늘지 않으면 오히려 손해**(STANDARD가 체험으로 내려감). 손익분기는 수주 약 +10~15%. 수주가 +30% 이상 늘면 이득이고 리뷰도 빨리 쌓임. 단, 수주 증가율은 가정이며 등록 후 실측해야 함
