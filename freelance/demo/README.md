# 포트폴리오 데모 (한글 데이터)

크몽·숨고 포트폴리오용 데모 2종. 샘플(`samples/`)이 영어 연습 사이트 기반이라 보여주지 못한 **한글 데이터 처리 능력**을 시연함.

| 데모 | 보여주는 것 | 결과물 |
|---|---|---|
| `01_korean_admin_division.py` | 한글 공개 웹페이지 표 수집 → 정제 → 자동 검증 → 서식 있는 엑셀 | `sample_output/demo1_korean_admin_division.xlsx`, `images/demo1_*.png` |
| `02_branch_sales_report.py` | 지점별 파일 취합(cp949/utf-8 혼합, 잠금파일, 양식 오류 파일) → 월별 피벗 | `sample_output/demo2_branch_sales_report.xlsx`, `images/demo2_*.png` |
| `render_preview.py` | 결과 시트를 표 이미지(PNG)로 렌더링 | `images/` |

## 실행
```bash
pip install -r ../samples/requirements.txt playwright
python 01_korean_admin_division.py --out ../sample_output/demo1_korean_admin_division.xlsx
python 02_branch_sales_report.py   --out ../sample_output/demo2_branch_sales_report.xlsx
python render_preview.py           # 이미지 재생성 (Chromium 필요)
```

## 데모 1: 무엇을 처리하는가
대상은 한국어 위키백과 '대한민국의 행정 구역' 표임. 원본 표는 그대로 쓸 수 없는 상태였음.
- 각주 표기 `[a]`, `[g]` 제거 / `빈칸` → 0 / 괄호 숫자 `(17)` → 17 / 합계 행('계') 분리
- 표 위치가 바뀌어도 열 이름(`행정 구역`, `넓이`, `인구`)으로 대상 표를 찾음
- 인코딩 선언이 없는 HTML도 utf-8 → cp949 순서로 직접 디코딩
- 결과 엑셀: 정제본(숫자 서식, 인구밀도 계산, 인구 막대 차트) / 원본 / 검증

### 검증에서 발견된 사실 (중요)
시도별 합계가 표의 '계' 행과 **일치하지 않음**.

| 항목 | 시도 합계 | 표의 '계' | 차이 |
|---|---|---|---|
| 면적(km2) | 100,396.01 | 100,387.40 | +8.61 |
| 인구(명) | 51,586,458 | 51,829,538 | -243,080 |

- 정제 코드를 거치지 않은 pandas 원본 합계도 같은 값이므로 **수집·정제 오류가 아니라 원본 표 내부의 불일치**임.
- 원인(문서 수정 시점 차이 등)은 확인하지 못했음. 그래서 값을 임의로 맞추지 않고 검증 시트와 경고로 노출함. `--strict`를 주면 불일치 시 종료 코드 2.
- 실제 납품에서도 "수집은 했지만 원본 자체가 틀렸다"를 고객에게 알려주는 절차로 쓸 수 있음.

## 데모 2: 무엇을 처리하는가
- 입력은 **시연용 가상 데이터**임 (난수 시드 고정, 실제 매출·고객 정보 아님).
- 일부러 섞어 둔 문제: cp949 CSV 3개 + utf-8 CSV 2개 / 엑셀 잠금파일 `~$...` / `매출` 컬럼이 없는 양식 오류 파일
- 결과: 잠금파일은 자동 제외, 양식 오류 파일은 경고 후 제외, 나머지 5개 파일 45행 취합, 지점×월 피벗과 합계

## 이미지에 대한 주의
`images/*.png`는 실제 엑셀 화면 캡처가 **아니라** 결과 시트 내용을 HTML 표로 그려 캡처한 미리보기임 (차트 제외). 상품 페이지에 쓸 때는 "결과 미리보기"로 표기하고, 가능하면 본인 PC에서 실제 엑셀 화면을 캡처해 교체할 것.
