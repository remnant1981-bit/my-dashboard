# 숨고 고수 프로필 / 견적 문구 초안

**서비스**: 업무 자동화(엑셀 매크로/VBA, Python), 웹 크롤링

**소개문**
엔지니어링 실무에서 자동화와 문서 작업을 해온 개발자입니다. (소속·과제·고객 정보는 기재하지 않습니다.) 반복 업무를 Python/엑셀로 자동화해 드립니다. 요구사항 정리 → 제작 → 사용 가이드까지 한 번에 납품합니다.

**견적 첫 문장(템플릿)**
안녕하세요. 요청하신 [작업명]은 [방식]으로 [기간]일 내 제작 가능합니다. 우선 [샘플/대상 파일] 한 가지만 보내주시면 정확한 견적을 드리겠습니다.

**가격 가이드(안)**: 단순 수식 3~8만 / 매크로·VBA 8~25만 / 크롤링 8~50만 (조사 평균 기준, 추정)

**첫 거래용 체험(4만)**: 공개 정적 페이지 1개·항목 5개 이하·최대 300행의 수집 결과 파일 1회 납품 (프로그램·소스 미포함). 범위를 넘으면 정규 견적. 조건은 `listing_kmong.md`와 동일

**2순위 서비스(민간 대상, 현재 보류)**: 사업계획서·회사소개서 구성 설계·첨삭. 정부지원사업 제출용이면 수주하지 않음 → 의뢰 시 사용 목적을 먼저 확인하고, 정부과제 제출용이면 정중히 거절.

**등록 선행 조건**: 소속사 겸업 허가/확인 완료 전에는 프로필 공개·견적 발송 금지 (contract_checklist.md 참고)
