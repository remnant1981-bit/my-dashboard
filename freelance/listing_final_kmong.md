## 상품 1: 웹 데이터 수집 + 엑셀 정리

### 1) 제목
> 웹 데이터 수집 + 엑셀 정리·검증까지 자동화 프로그램 제작 (한글 사이트 OK)

### 2) 패키지 3칸 (패키지 설정 ON)
| 크몽 칸 | 패키지 제목 | 패키지 설명 | 가격 | 작업일 | 수정 |
|---|---|---|---|---|---|
| STANDARD | 체험 · 결과 파일 1회 | 공개 정적 페이지 1곳, 항목 5개 이하, 최대 300행을 수집해 엑셀/CSV 파일로 1회 전달 (프로그램·소스 미포함) | 40,000원 | 2일 | 1회 |
| DELUXE | 수집 프로그램 제작 | 동적(JS) 페이지·페이지 넘김 수집 프로그램 + 소스코드 + 사용법. 수집 대상 1개 사이트, 항목 10개 이하 | 150,000원 | 5일 | 2회 |
| PREMIUM | 수집 + 변경 알림 + 정기 실행 | DELUXE 전체 + 변경 감지 알림 + 결과 자동 검증 + 윈도우 작업 스케줄러 정기 실행 안내 | 300,000원 | 7일 | 3회 |

메모
- 예전 STANDARD(8만원, 정적 페이지 1개 프로그램 납품)는 칸에서 빠짐 → 본문과 FAQ에서 "문의 시 견적(8만원~)"으로 안내함
- 체험은 제작자가 직접 수집을 실행하는 방식이라 건마다 `tools/check_robots.py` 결과와 약관 확인을 기록할 것
- 체험은 리뷰 5건 확보 시점까지 운영 후 유지 여부 재검토 (`tracking/`에 기록하면 `simulation/calibrate.py`로 효과 확인 가능)

### 3) 서비스 설명 (본문)
> **이런 분께 필요합니다**
> - 웹사이트에서 같은 데이터를 매번 복사·붙여넣기 하시는 분
> - 수집한 데이터를 엑셀로 다시 정리하느라 시간을 쓰시는 분
> - 한글 페이지나 한글 엑셀 파일에서 글자가 깨져 고생하신 분
>
> **처음이라 망설여지신다면 체험부터**
> 공개된 웹페이지 1곳에서 원하는 항목(5개 이하, 최대 300행)을 수집해 엑셀 파일로 드립니다. 결과를 보시고 마음에 드시면 직접 실행할 수 있는 프로그램 제작으로 이어가실 수 있습니다.
>
> **받으시는 것 (DELUXE 이상)**
> 1. 원하는 웹페이지의 목록·상세 데이터를 엑셀(CSV)로 저장하는 프로그램과 소스코드
> 2. 실행 방법 설명서와 샘플 결과 파일
> 3. (PREMIUM) 수집 결과 자동 검증 — 건수 확인, 빈 값·형식 이상 표시
> 4. (PREMIUM) 변경 감지 알림, 정기 실행(작업 스케줄러) 등록 안내
>
> **정적 페이지 1곳만 반복 수집하는 간단한 프로그램**은 문의 주시면 견적(8만원~)으로 안내드립니다.
>
> **작업 범위**
> - 포함: 수집 대상 1개 사이트(항목은 협의 후 확정), 한글 페이지 인코딩 처리, 엑셀 서식 정리, 수정 횟수 내 형식 수정
> - 제외: 로그인이 필요한 서비스, 개인정보 수집, 이용약관·robots.txt상 수집이 금지된 사이트, 대상 사이트 구조 변경 후의 유지보수(별도 협의)
>
> **진행 과정**
> 문의 → 요구사항 확인 → 수집 가능 여부(약관·robots.txt) 확인 → 견적 → 제작 → 납품·검수 → 수정
>
> **작업 예시 (시연 자료)**
> - 한국어 위키백과의 표를 수집해 각주·빈칸·괄호 숫자를 정리하고 엑셀로 저장했습니다. 정리 후 합계를 원본의 '계' 행과 자동 대조하는 과정에서 원본 표 자체의 불일치를 찾아 경고로 표시했습니다. (출처: 한국어 위키백과, CC BY-SA 4.0)
> - 지점별 CSV 5개(한글 인코딩 혼합, 잠금파일·양식 오류 파일 포함)를 취합해 월별 보고서를 만들었습니다. (시연용 가상 데이터)
> - 이미지는 결과 시트를 표로 그린 미리보기입니다.

### 4) FAQ
> **Q. 로그인해야 보이는 데이터도 되나요?**
> A. 로그인이 필요한 서비스와 개인정보는 진행하지 않습니다.
>
> **Q. 어떤 사이트든 가능한가요?**
> A. 이용약관과 robots.txt를 먼저 확인하고, 수집이 어려우면 진행하지 않거나 공공 API 같은 대안을 안내드립니다.
>
> **Q. 체험과 DELUXE는 뭐가 다른가요?**
> A. 체험은 제가 수집한 결과 파일만 1회 드립니다. DELUXE부터는 직접 반복해서 실행할 수 있는 프로그램과 소스코드를 드립니다.
>
> **Q. 체험 범위를 넘으면요?**
> A. 항목·행 수가 범위를 넘거나 동적 페이지라면 DELUXE 이상 또는 견적으로 안내드립니다.
>
> **Q. 간단한 수집 프로그램만 필요한데요?**
> A. 정적 페이지 1곳을 반복 수집하는 프로그램은 견적(8만원~)으로 진행합니다. 문의 주세요.
>
> **Q. 사이트 구조가 바뀌면요?**
> A. 납품 후 7일간은 납품 범위 안의 오류를 무상으로 수정합니다. 사이트 구조 변경에 따른 수정은 별도 협의입니다.
>
> **Q. 소스코드 소유권은요?**
> A. 대금 완납(구매확정) 시 의뢰인께 귀속됩니다. 체험은 결과 파일만 제공합니다.
>
> **Q. 파이썬이 없는 PC인데요?**
> A. 설치 방법을 안내드리며, 원격 설치 지원은 별도 협의입니다.

## 상품 2: 엑셀 취합·보고서 자동화 (같은 안 A 규칙 적용)

> 상품 2는 이전까지 가격만 있고 칸별 범위가 정해져 있지 않았음. 상품 1과 같은 규칙(STANDARD 칸 = 체험, 8만원 = 견적)으로 아래 **범위·작업일을 새로 제안**함. 본인 검토 필요.

### 1) 제목
> 여러 엑셀·CSV 파일 자동 취합 + 월별 보고서 생성 (한글 파일 OK)

### 2) 패키지 3칸
| 크몽 칸 | 패키지 제목 | 패키지 설명 | 가격 | 작업일 | 수정 |
|---|---|---|---|---|---|
| STANDARD | 체험 · 취합 결과 1회 | 같은 양식 파일 5개 이하를 합친 결과 엑셀 1회 전달 (프로그램 미포함) | 40,000원 | 2일 | 1회 |
| DELUXE | 취합·요약 프로그램 | 같은 양식 파일 개수 제한 없이 취합 + 요약/피벗 시트 + 한글 인코딩·잠금파일·양식 오류 파일 자동 처리. 프로그램 + 소스 + 사용법 | 150,000원 | 4일 | 2회 |
| PREMIUM | 다양식 취합 + 보고서 | DELUXE 전체 + 열 이름이 다른 양식 최대 3종 매핑 + 서식·차트가 있는 보고서 + 더블클릭 실행 파일과 정기 실행 안내 | 250,000원 | 6일 | 3회 |

### 3) 서비스 설명 (본문)
> **이런 분께 필요합니다**
> - 지점·부서별로 받은 엑셀 파일을 매달 손으로 합치시는 분
> - CSV를 열면 한글이 깨지거나, 양식이 조금씩 달라 정리가 오래 걸리는 분
>
> **처음이라 망설여지신다면 체험부터**
> 같은 양식의 파일 5개 이하를 합친 결과 엑셀을 드립니다. 마음에 드시면 매달 직접 돌릴 수 있는 프로그램으로 이어가실 수 있습니다.
>
> **받으시는 것 (DELUXE 이상)**
> - 폴더의 파일을 한 번에 취합하는 프로그램과 소스코드, 사용법
> - 요약·피벗 시트 자동 생성, 어느 파일에서 온 행인지 표시
> - 한글 CSV(cp949)·엑셀 혼합, 엑셀 잠금파일, 필수 항목이 빠진 파일을 자동으로 걸러 경고
> - (PREMIUM) 열 이름이 다른 양식 매핑, 서식·차트 보고서, 더블클릭 실행
>
> **간단한 1회성 취합 프로그램**은 문의 주시면 견적(8만원~)으로 안내드립니다.
>
> **작업 예시 (시연 자료)**
> 지점별 CSV 5개(한글 인코딩 혼합, 잠금파일·양식 오류 파일 포함)를 취합해 월별 보고서를 만들었습니다. 시연용 가상 데이터이며 이미지는 결과 미리보기입니다.

### 4) FAQ
> **Q. 체험과 DELUXE는 뭐가 다른가요?**
> A. 체험은 합친 결과 파일만 1회 드립니다. DELUXE부터는 매번 직접 실행할 수 있는 프로그램과 소스코드를 드립니다.
>
> **Q. 파일 양식이 조금씩 다른데요?**
> A. 열 이름이 다른 양식은 PREMIUM에서 3종까지 맞춰 드립니다. 그 이상은 견적으로 안내드립니다.
>
> **Q. 회사 자료를 보내도 되나요?**
> A. 작업에 필요한 범위만 받고, 납품 후 파기합니다. 개인정보가 포함된 파일은 가린 뒤 보내 주세요.

## 시뮬레이션과의 차이 (내부 메모)
`simulation/`의 체험 비교는 8만원 상품이 계속 팔린다고 가정함. 안 A에서는 8만원이 견적으로만 남아 실제 비중이 더 낮을 수 있음. 등록 후 `tracking/log.csv`에 실제 판매 금액을 적으면 `calibrate.py`가 실제 비중과 가격으로 다시 계산하므로 별도 수정은 하지 않았음.
