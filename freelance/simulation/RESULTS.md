# 수익 시뮬레이션 결과 (몬테카를로, 시드 42, 10,000회)

> **모든 입력값은 가정이며 실측 데이터가 아님.** 특히 '주당 기본 문의 수'와 '전환율'은 근거 데이터가 없음.
> 겸업 허가·계정 개설 기간은 포함하지 않음 (등록 시점부터 26주). 재현: `python revenue_sim.py`

## 모델 요약
- 문의 ~ Poisson(기본 문의율 x (1 + 0.12 x 리뷰수), 최대 3배) → 거절(위험 건) → 수주(전환율은 리뷰 따라 상승)
- 패키지 믹스 50/30/20% (8/15/30만원), 작업일 3/5/7일, 주당 가용 작업일만큼 FIFO 처리
- 완료 건 95% 정산(1주 지연), 수수료 20%, 원천징수 3.3% → 총액의 약 77%가 실수령
- 목표: 실수령 누적 100만원

## 해석
- **병목은 제작 용량이 아니라 문의 수(노출)**. 작업일을 3→6일로 늘려도 기본 시나리오는 거의 변하지 않음.
- 기본 가정(문의 주 0.7건)에서는 26주 내 100만원 달성이 사실상 불가(1%). 달성하려면 문의가 주 3~5건 이상 필요.
- 가격 인상(x1.5)은 효과가 있으나 단독으로는 부족. 노출 확대와 병행해야 함.
- 문의 수는 가정이므로, 실제 등록 후 2~4주간 문의 수를 측정해 이 시뮬레이션에 넣고 재실행해야 의미 있는 예측이 됨.
