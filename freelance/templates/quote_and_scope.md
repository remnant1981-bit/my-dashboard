# 견적서 / 작업 범위 확인서 (복사해서 사용)

## 1. 요구사항 문진표 (문의 오면 먼저 보내기)
1. 수집/자동화 대상 (URL 또는 파일 예시 1개)
2. 필요한 항목(컬럼) 목록
3. 로그인이 필요한 사이트인가? (필요하면 수주 불가)
4. 개인정보가 포함되는가? (포함되면 수주 불가)
5. 실행 주기 (1회 / 매일 / 매시간)
6. 결과 형식 (엑셀 / CSV / DB / 메일 알림)
7. 실행 환경 (Windows / Mac, 파이썬 설치 여부)
8. 희망 납기, 예산

## 2. 견적서
| 항목 | 내용 |
|---|---|
| 작업명 | |
| 작업 범위 | (대상 1개, 항목 N개, 결과 형식) |
| 제외 범위 | 로그인/개인정보/대상 사이트 구조 변경 이후 유지보수 |
| 금액 | 원 (VAT 별도/포함 표기) |
| 작업일 | 영업일 일 |
| 수정 | 회 (범위 내 수정만, 범위 추가는 별도 견적) |
| 검수 | 납품 후 3일 내 이의 제기, 이후 확정 |
| 소스 소유권 | 대금 완납 시 의뢰인에게 귀속 |
| 유지보수 | 납품 후 7일 무상 버그 수정 (대상 사이트 변경은 제외) |

## 3. 가격 산정 가이드 (조사 평균 기준, 추정)
- 정적 페이지 1개 / 항목 10개 이하: 8~15만
- 동적(JS) 페이지 또는 다중 페이지: 15~30만
- 정기 실행 + 알림 + 설치 지원: 30~50만
- 엑셀 취합/보고서 자동화: 8~25만
- 첫 1~2건은 리뷰 확보용으로 하단 가격 적용 권장
