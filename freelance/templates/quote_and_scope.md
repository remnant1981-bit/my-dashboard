# 견적서 / 작업 범위 확인서 (복사해서 사용)

## 1. 요구사항 문진표 (문의 오면 먼저 보내기)
1. 수집/자동화 대상 (URL 또는 파일 예시 1개)
2. 필요한 항목(컬럼) 목록
3. 로그인이 필요한 사이트인가? (필요하면 수주 불가)
4. 개인정보가 포함되는가? (포함되면 수주 불가)
5. 수집 데이터의 사용 목적 (재판매/재배포 여부)
6. 실행 주기 (1회 / 매일 / 매시간)
7. 결과 형식 (엑셀 / CSV / 알림)
8. 실행 환경 (Windows / Mac, 파이썬·Chrome 설치 여부)
9. 희망 납기, 예산

## 3. 면책/책임 조항 (문구 초안, 법률 검토 권장)
- 의뢰인은 대상 사이트의 이용약관·robots.txt 및 관련 법령에 따라 수집·이용할 권한이 있음을 확인한다.
- 제작자는 수주 전 약관·robots.txt를 확인하고 위험이 있으면 수주를 거절할 수 있다.
- 합의된 범위를 벗어난 수집·이용으로 발생한 문제의 책임은 의뢰인에게 있다.
- 제작자는 대상 사이트의 구조·정책 변경으로 인한 동작 불가를 보증하지 않는다.

## 4. 가격 산정 가이드 (조사 평균 기준, 추정)
- **체험(첫 거래용)**: 4만 — 공개 정적 페이지 1개, 항목 5개 이하, 최대 300행의 **수집 결과 파일 1회 납품** (프로그램·소스 미포함, 수정 1회, 2일). 범위를 넘으면 아래 정규 가격 적용
- 정적 페이지 1개 / 항목 10개 이하: 8~15만
- 동적(JS) 페이지 또는 다중 페이지: 15~30만
- 정기 실행 + 알림 + 설치 지원: 30~50만
- 엑셀 취합/보고서 자동화: 8~25만
- 첫 1~2건은 리뷰 확보용으로 하단 가격 적용 권장 (플랫폼 수수료·세금 후 실수령은 listing_kmong.md 하단 참고)
