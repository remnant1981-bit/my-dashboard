# [프로젝트명] 사용 설명서

> 납품 시 `[ ]` 부분을 채워서 고객에게 전달. 이 안내문 아래 "제작자 체크" 구간은 삭제 후 전달.

## 1. 구성 파일
| 파일 | 설명 |
|---|---|
| `run.bat` | 더블클릭으로 실행 (Windows) |
| `[스크립트명].py` | 본 프로그램 |
| `requirements.txt` | 필요한 파이썬 패키지 목록 |
| `result_sample.xlsx` | 샘플 결과 (실행 전 예시) |

## 2. 처음 한 번만
1. 파이썬 3 설치: python.org → 설치 시 **"Add Python to PATH" 체크**
2. 이 폴더를 원하는 위치에 복사 (경로에 한글·공백이 있어도 되지만, 문제가 있으면 `C:\work` 같은 짧은 경로 사용)

## 3. 실행
- `run.bat` 더블클릭. 처음 실행 때는 패키지 설치 때문에 몇 분 걸릴 수 있음 (인터넷 필요).
- 직접 실행: `python [스크립트명].py [옵션]`

### 주요 옵션
| 옵션 | 설명 | 기본값 |
|---|---|---|
| `[--옵션1]` | [설명] | [값] |
| `--delay` | 요청 사이 대기 시간(초). 늘리면 차단 가능성이 줄어듦 | 1.0 |
| `--out` | 결과 파일 이름 | `result.xlsx` |

## 4. 결과
- 결과 파일: `[result.xlsx]` — 컬럼: [컬럼 설명]
- 한글이 깨지면: CSV는 엑셀에서 "데이터 → 텍스트/CSV 가져오기 → UTF-8"로 열기 (xlsx는 해당 없음)

## 5. 자주 나는 문제
| 증상 | 원인 | 해결 |
|---|---|---|
| `Python was not found` | 파이썬 미설치/PATH 미체크 | 파이썬 재설치 시 PATH 체크 |
| 패키지 설치 실패 | 인터넷/보안 프로그램 | 네트워크 확인 후 재실행, 사내망이면 IT 담당자 문의 |
| 결과가 0건 | 대상 사이트 구조 변경 | 선택자 수정 필요 → 유지보수 범위 확인 |
| 중간에 멈춤/차단 | 요청이 너무 빠름 | `--delay` 값을 늘려 재시도 |
| 종료 코드 1 | 일부 페이지 수집 실패 | 메시지 확인. 성공한 데이터는 저장됨 |

## 6. 사용 시 주의
- 대상 사이트의 이용약관·robots.txt를 준수할 책임은 이용자에게 있으며, 합의된 범위 밖의 수집·이용은 허용되지 않음.
- 수집한 데이터에 개인정보가 포함되어서는 안 됨.
- 계정·키 정보는 코드에 쓰지 말고 환경변수로 설정할 것.

- 대상 사이트 구조·정책 변경으로 인한 수정은 별도 협의
