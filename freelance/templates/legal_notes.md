# 크롤링·자동화 법적/약관 유의 (일반 정보, 법률 자문 아님)

> 아래는 확인 포인트 정리이며 법적 판단이 아님. 분쟁 소지가 있는 건은 수주 전 변호사 확인 권장.

## 수주 전 확인 (3단계)
1. 대상 사이트 이용약관에 자동 수집 금지 조항이 있는가
2. `robots.txt` 에서 해당 경로 접근이 허용되는가 (`https://대상/robots.txt`)
   - 자동 점검: `python tools/check_robots.py <대상URL>` (종료 코드 0 허용 / 1 불허 / 2 확인 불가). 401·403·5xx 응답은 보수적으로 불허 처리함. **robots.txt 허용이 약관 허용은 아님**
3. 수집 데이터에 개인정보(이름·연락처·계정 등)가 포함되는가

하나라도 위험하면 **수주하지 않음**. 공공데이터포털 등 오픈API·공개 라이선스 데이터를 우선 제안.

## 위험 영역 (확인 필요 항목)
| 영역 | 내용 |
|---|---|
| 정보통신망법 | 접근 권한 없는 곳 접속·로그인 우회, 서버에 과부하를 주는 수집은 부정 접속/업무방해 문제 소지 |
| 저작권법 | 데이터베이스 제작자의 권리, 수집 데이터의 재판매·재배포 제한 가능 |
| 개인정보보호법 | 개인정보 수집·처리는 별도 근거 필요, 원칙적으로 수주 제외 |
| 계약상 책임 | 약관 위반 소지를 알고 제작하면 제작자도 책임을 질 수 있음(추정). "책임은 이용자" 문구만으로 면책되지 않을 수 있음 |

## 코드 원칙
- 요청 간 delay 유지(기본 1초 이상), User-Agent로 수집 주체 식별 가능하게
- 로그인 필요/우회/캡차 해제 요구는 거절
- 수집 범위는 계약서에 명시한 항목·사이트로 한정
