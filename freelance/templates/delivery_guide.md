# 납품 가이드 (의뢰인에게 함께 전달)

## 납품물
- 소스코드 (.py), requirements.txt
- 사용 설명서 (아래 양식)
- 샘플 결과 파일 1개

## 사용 설명서 양식
1. 설치: `pip install -r requirements.txt`
2. 실행: `python main.py --옵션 값`
3. 결과 위치와 컬럼 설명
4. 자주 나는 오류와 해결법
   - 대상 사이트 구조 변경 시: 선택자(CSS selector)를 수정해야 함 → 수정 요청 시 별도 협의
   - 접속 차단/속도 제한: `--delay` 값을 늘려 재시도
5. 주의: 대상 사이트 약관·robots.txt 준수 책임은 이용자에게 있음
