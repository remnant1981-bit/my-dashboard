# 수익화 프로젝트: 크롤링/업무 자동화 외주

근거: 시장 조사 결과 1순위 D(크롤링/Selenium), 보조 C(엑셀 자동화). 2순위 A(민간 사업계획서·IR).
단가 근거(크몽/숨고 집계): 크롤링 평균 30만 / 매크로·자동화 평균 15~20만 → 3~5건으로 100만원.

- `listing_soomgo.md` 숨고 고수 프로필/견적 문구 초안
